## Threat Model

cybergarage-upnp is a Java UPnP library plus tools and examples. core implements SSDP discovery, HTTP, SOAP device actions and GENA subscriptions; std supplies AV servers/controllers/renderers, while tools include IGD support. Normal use embeds Device or ControlPoint in an application; examples expose Swing or console applications. Network discovery feeds remote description fetching and XML parsing; device HTTP requests dispatch to application listeners; subscriptions cause outbound notifications; optional media directories intend to expose catalogued files. #### Summary

Network-supplied SOAP, GENA or device description XML reaches the bundled `JaxpParser`, whose default factory permits external resource resolution. A reachable peer can invoke host file reads and secondary requests.

#### Root Cause

`SOAPRequest.getRootNode()` wraps received bytes in a stream and calls the shared parser. `UPnP.loadDefaultXMLParser()` tries optional parsers, then the bundled `JaxpParser`. Its `DocumentBuilderFactory` has no DOCTYPE/entity/access restrictions before `builder.parse()`, so parser-controlled resource resolution runs with JVM authority.

### [2] HTTP messages can exhaust JVM heap before routing

| Field | Value |
| --- | --- |
| Severity | medium |
| Confidence | high |
| Confidence rationale | Independent baseline and parent source traces agree; no runtime exploit reproduction. Deployment/JVM prerequisites are explicit. |
| Category | resource-exhaustion |
| CWE | CWE-400 |
| Affected lines | core/src/main/java/org/cybergarage/http/HTTPServerThread.java:37-48, core/src/main/java/org/cybergarage/http/HTTPPacket.java:143-153, core/src/main/java/org/cybergarage/http/HTTPPacket.java:220-243 |

#### Summary

Request lines, headers and bodies are buffered without total size limits, allowing a reachable client to consume JVM heap before an application handles its request.

#### Root Cause

`readLine()` accumulates until LF without a length cap. Header parsing has no count/aggregate limit. Content length drives byte accumulation into an unbounded `ByteArrayOutputStream`, and conversion copies the body. Chunk-size configuration only limits each temporary read.

**Parser precedes dispatcher** — `core/src/main/java/org/cybergarage/http/HTTPServerThread.java:37-48`

Network input is parsed before routing or application validation.

```java

    while (httpReq.read() == true) {
      httpServer.performRequestListener(httpReq);
      if (httpReq.isKeepAlive() == false) break;
    }
    httpSock.close();
  }
```

#### Summary

A malicious media server can return cyclic container IDs and indefinitely grow recursive Browse calls when an embedding application enables recursion via the four-argument `MediaController.browse()` API.

#### Root Cause

The public four-argument `browse()` forwards `hasRootNodeMetadata` into private traversal as the recursion flag. Remote Result XML supplies each container's ID and childCount. Each positive childCount appends a new node and recurses with supplied ID, without tracking previously visited IDs, maximum depth, node count or operation budget. A repeated container therefore retains all prior nodes and stack frames.
