Threat Model

cybergarage-upnp is a Java UPnP library plus tools and examples. core implements SSDP discovery, HTTP, SOAP device actions and GENA subscriptions; std supplies AV servers/controllers/renderers, while tools include IGD support. Normal use embeds Device or ControlPoint in an application; examples expose Swing or console applications. Network discovery feeds remote description fetching and XML parsing; device HTTP requests dispatch to application listeners; subscriptions cause outbound notifications; optional media directories intend to expose catalogued files.
